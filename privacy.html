Privacy

Last updated: 14 September 2026

Cyclea is a menstrual cycle tracker. It does not show ads and it does not sell health data.

What we store

In guest mode, period days, flow, symptoms, notes, theme, and disclaimer acceptance stay on this device (Hive / IndexedDB in the browser, or local app storage on Android). Nothing is sent to a Cyclea server because there is no Cyclea backend besides the optional Firebase project you configure.

If a maintainer enables Google Sign-In, logs can sync to Cloud Firestore under users/{your user id}/logs/ in that Firebase project. Authentication is handled by Google / Firebase Auth.

What we do not do

  • No advertising SDKs.
  • No sale of cycle, symptom, or account data.
  • No community graph, partner sharing, or wearable ingestion in Phase 1.

Your controls

Use Settings → Delete all Cyclea data to wipe local logs. If you are signed in, that action also deletes your Cyclea Firestore log documents. You can sign out without deleting local data. You may also delete the Firebase user in Google’s account tools if the project owner enabled Google Auth.

Health information

Cycle and symptom logs are sensitive. Treat a shared device as untrusted: use OS user profiles or sign out, and use Delete all before handing a phone over. Cyclea is not a covered medical-records system and is not HIPAA-certified.

Web hosting

The static web app may be hosted on GitHub Pages. GitHub’s own logs (IP addresses for downloads) are governed by GitHub’s privacy policy, not by Cyclea.

Contact

Questions about this notice can be opened as a GitHub issue on the Cyclea repository.
